Answer: A) The 2 extra electrons form a lone pair on S. SO₃ has 24 e⁻ (3 domains on S). SO₃²⁻ has 26 e⁻: the extra 2 become a lone pair on S, giving 4 domains, 3 atoms and a trigonal pyramidal shape.

27Molecular Polarity

CCl₄ has four polar C–Cl bonds. Why is the molecule nonpolar?

Show answer

C) It is tetrahedral with 4 identical atoms, so the dipoles cancel. Four equal vectors to the corners of a tetrahedron add to zero (NCERT Table 4.5: CCl₄ = 0 D).

Answer: C) It is tetrahedral with 4 identical atoms, so the dipoles cancel. Four equal vectors to the corners of a tetrahedron add to zero (NCERT Table 4.5: CCl₄ = 0 D).

29Molecular Polarity

The formate ion, HCO₂⁻, is trigonal planar. Is it polar?

Show answer

A) Yes: the outer atoms are not all the same (H vs O). A symmetric shape cancels only if all the outer atoms are identical. The strong C–O dipoles are not balanced by the weak C–H.

Answer: A) Yes: the outer atoms are not all the same (H vs O). A symmetric shape cancels only if all the outer atoms are identical. The strong C–O dipoles are not balanced by the weak C–H.

30Molecular Polarity

Show answer

D) H₂O is bent, CO₂ is linear. The shape decides it. The bent H₂O's dipoles add (2µ cos 52.25°), while the linear CO₂'s point in opposite directions and cancel.

Answer: D) H₂O is bent, CO₂ is linear. The shape decides it. The bent H₂O's dipoles add (2µ cos 52.25°), while the linear CO₂'s point in opposite directions and cancel.

Complete every column of the worksheet row for SO₂: valence e⁻, Lewis structure, electron geometry, molecular geometry & bond angle, the 3-D redraw, bond polarity and molecular polarity.

Show worked solution
  • Valence e⁻: 6 + 2(6) = 18.
  • Lewis: O–S–O uses 4, each O takes 3 lone pairs (12), and the last 2 go on S as a lone pair. S has only 6, so make one S=O. There are 2 resonance forms (O=S–O ↔ O–S=O).
  • Electron geometry: S has 2 atoms + 1 lone pair = 3 domains, so trigonal planar.
  • Molecular geometry: bent, slightly less than 120° (NCERT Table 4.8: 119.5°).
  • Redraw: all in one plane: the lone pair on top of S and the O atoms at lower left and right.
  • Bond polarity: S–O: 3.5 − 2.5 = 1.0, polar.
  • Molecular polarity: polar. It is bent, so the two S–O dipoles add.

Complete the row for CHCl₃, then explain in one or two sentences why CHCl₃ is polar while CCl₄ is not.

Show worked solution
  • Valence e⁻: 4 + 1 + 3(7) = 26.
  • Lewis: C in the centre with single bonds to H and three Cl; each Cl has 3 lone pairs. All formal charges are 0.
  • Electron geometry: 4 atoms + 0 lone pairs = 4 domains, so tetrahedral.
  • Molecular geometry: tetrahedral, 109.5°.
  • Redraw: 2 plain lines, 1 wedge and 1 dash (put H anywhere).
  • Bond polarity: C–H 0.4 is nonpolar; C–Cl 0.5 is polar.
  • Molecular polarity: polar. In CCl₄ four identical dipoles cancel (0 D). Replacing one Cl with H removes one of them, so the rest no longer cancel. NCERT Table 4.5: CHCl₃ = 1.04 D.
