Lesson Plan

Objectives. By the end of this session the student should be able to:

  1. Find real nth roots, and say when an even root has two, one or no real values.
  2. Evaluate am/na^{m/n} without a calculator, including negative bases and negative exponents.
  3. Switch between radical form and rational-exponent form.
  4. Solve equations of the form axn=cax^n = c and xm/n=cx^{m/n} = c.
  5. Simplify multistep expressions with rational exponents, and write radicals in simplest form (including rationalizing a denominator).
  6. Graph y=ax−h+ky = a\sqrt{x - h} + k and y=ax−h3+ky = a\sqrt[3]{x - h} + k, and state their domain and range.

Part 1 — nth Roots and Rational Exponents (10 min)

nth roots

If bn=ab^n = a, then b is an nth root of a, written an\sqrt[n]{a}. n is the index.

How many real nth roots a number has depends on whether n is odd or even:

a>0a > 0 a=0a = 0 a<0a < 0
n odd one real root: 83=2\sqrt[3]{8} = 2 0 one real root: −83=−2\sqrt[3]{-8} = -2
n even two real roots: ±164=±2\pm\sqrt[4]{16} = \pm 2 0 no real root: −164\sqrt[4]{-16} is not real

Why: an odd power keeps the sign ((−2)3=−8(-2)^3 = -8), so a negative number has an odd root. An even power is never negative ((±2)4=16(\pm 2)^4 = 16), so a negative number has no real even root.

Why a1/na^{1/n} means the nth root

The power-of-a-power rule must still hold for fractions. Raise a1/na^{1/n} to the nth power:

(a1/n)n=a1n⋅n=a1=a\left(a^{1/n}\right)^n = a^{\frac{1}{n}\cdot n} = a^1 = a

So a1/na^{1/n} is the number whose nth power is a: it is an\sqrt[n]{a}. Then am/n=(a1/n)m=(an)ma^{m/n} = \left(a^{1/n}\right)^m = \left(\sqrt[n]{a}\right)^m.

Read the fraction as an instruction: the denominator is the root, the numerator is the power (“power over root”). Take the root first so the numbers stay small.

Worked Example 1: evaluate without a calculator

  • 642/3=(643)2=42=1664^{2/3} = \left(\sqrt[3]{64}\right)^2 = 4^2 = 16
  • (−32)3/5=(−325)3=(−2)3=−8(-32)^{3/5} = \left(\sqrt[5]{-32}\right)^3 = (-2)^3 = -8 (odd root of a negative is fine)
  • 9−3/2=193/2=1(9)3=1279^{-3/2} = \dfrac{1}{9^{3/2}} = \dfrac{1}{(\sqrt{9})^3} = \dfrac{1}{27}
  • (1681)3/4=(164)3(814)3=2333=827\left(\dfrac{16}{81}\right)^{3/4} = \dfrac{(\sqrt[4]{16})^3}{(\sqrt[4]{81})^3} = \dfrac{2^3}{3^3} = \dfrac{8}{27}
  • (−64)1/2(-64)^{1/2}: an even root of a negative number, not a real number.

Worked Example 2: rewrite between the two forms

  • x25=x2/5\sqrt[5]{x^2} = x^{2/5}, and (y4)3=y3/4\left(\sqrt[4]{y}\right)^3 = y^{3/4}
  • z3/2=z3=(z)3z^{3/2} = \sqrt{z^3} = (\sqrt{z})^3, and 7−1/3=1737^{-1/3} = \dfrac{1}{\sqrt[3]{7}}
  • A decimal exponent becomes a fraction first: 100.6=103/5=103510^{0.6} = 10^{3/5} = \sqrt[5]{10^3}

Worked Example 3: solve with nth roots

To solve xn=cx^n = c, take the nth root of both sides. With an even n, remember ±.

  • 4x5=1284x^5 = 128: x5=32x^5 = 32, so x=325=2x = \sqrt[5]{32} = 2 (odd index: one answer).
  • (x−3)4=21(x - 3)^4 = 21: x−3=±214x - 3 = \pm\sqrt[4]{21}, so x=3±214x = 3 \pm \sqrt[4]{21}, i.e. x≈5.14x \approx 5.14 or x≈0.86x \approx 0.86.
  • x2/3=16x^{2/3} = 16: raise both sides to the reciprocal power 32\tfrac{3}{2}. Since the numerator 2 is even, both signs work: (x1/3)2=16\left(x^{1/3}\right)^2 = 16 gives x1/3=±4x^{1/3} = \pm 4, so x=±64x = \pm 64. Check: (−64)2/3=(−4)2=16(-64)^{2/3} = (-4)^2 = 16 ✓

Part 2 — Properties and Multistep Expressions (14 min)

The method for any multistep expression

  1. Powers outside parentheses first: multiply every exponent inside by the outside exponent (power of a power), including the number’s.
  2. Evaluate numbers with rational exponents (root first, then power).
  3. Combine the same base: add exponents when multiplying, subtract when dividing. Use a common denominator for the fractions.
  4. Finish with positive exponents (move negative ones across the fraction bar), unless the question says otherwise.

Worked Example 4: multistep simplification (variables positive)

(a) (8x6y−3)2/3\left(8x^6y^{-3}\right)^{2/3}

=82/3x6⋅23y−3⋅23=4x4y−2=4x4y2= 8^{2/3}\,x^{6\cdot\frac{2}{3}}\,y^{-3\cdot\frac{2}{3}} = 4x^4y^{-2} = \frac{4x^4}{y^2}

(b) (a1/3b−1/2)6⋅a−1b4\left(a^{1/3}b^{-1/2}\right)^6 \cdot a^{-1}b^4

=a2b−3⋅a−1b4=a2−1b−3+4=ab= a^{2}b^{-3}\cdot a^{-1}b^{4} = a^{2-1}\,b^{-3+4} = ab

(c) (x3/4x1/4)−2\left(\dfrac{x^{3/4}}{x^{1/4}}\right)^{-2}

=(x34−14)−2=(x1/2)−2=x−1=1x= \left(x^{\frac{3}{4}-\frac{1}{4}}\right)^{-2} = \left(x^{1/2}\right)^{-2} = x^{-1} = \frac{1}{x}

(d) 61/2⋅61/36^{1/2}\cdot 6^{1/3}: add with a common denominator, 12+13=36+26=56\tfrac{1}{2} + \tfrac{1}{3} = \tfrac{3}{6} + \tfrac{2}{6} = \tfrac{5}{6}, so the answer is 65/66^{5/6}.

Simplest radical form

A radical is in simplest form when:

  1. the radicand has no factor that is a perfect nth power;
  2. there is no radical in a denominator;
  3. there is no fraction under the radical.

Worked Example 5: simplify radicals

  • 50x3y2=25x2y2⋅2x=5xy2x\sqrt{50x^3y^2} = \sqrt{25x^2y^2}\cdot\sqrt{2x} = 5xy\sqrt{2x} (x, y positive)
  • −54x43=−27x33⋅2x3=−3x2x3\sqrt[3]{-54x^4} = \sqrt[3]{-27x^3}\cdot\sqrt[3]{2x} = -3x\sqrt[3]{2x}
  • Like radicals (same index and radicand) add like like terms: 312−27=63−33=333\sqrt{12} - \sqrt{27} = 6\sqrt{3} - 3\sqrt{3} = 3\sqrt{3}, and 403+253=253+253=453\sqrt[3]{40} + 2\sqrt[3]{5} = 2\sqrt[3]{5} + 2\sqrt[3]{5} = 4\sqrt[3]{5}.

Worked Example 6: rationalize the denominator

  • 36=36⋅66=366=62\dfrac{3}{\sqrt{6}} = \dfrac{3}{\sqrt{6}}\cdot\dfrac{\sqrt{6}}{\sqrt{6}} = \dfrac{3\sqrt{6}}{6} = \dfrac{\sqrt{6}}{2}
  • 523=523⋅4343=54383=5432\dfrac{5}{\sqrt[3]{2}} = \dfrac{5}{\sqrt[3]{2}}\cdot\dfrac{\sqrt[3]{4}}{\sqrt[3]{4}} = \dfrac{5\sqrt[3]{4}}{\sqrt[3]{8}} = \dfrac{5\sqrt[3]{4}}{2} (multiply until the denominator is a perfect cube)
  • 21+3\dfrac{2}{1 + \sqrt{3}}: multiply by the conjugate 1−31 - \sqrt{3}, because (a+b)(a−b)=a2−b2(a + b)(a - b) = a^2 - b^2 removes the root:

2(1−3)(1+3)(1−3)=2(1−3)1−3=2(1−3)−2=3−1\frac{2(1 - \sqrt{3})}{(1 + \sqrt{3})(1 - \sqrt{3})} = \frac{2(1 - \sqrt{3})}{1 - 3} = \frac{2(1 - \sqrt{3})}{-2} = \sqrt{3} - 1

Part 3 — Radical Graphs (12 min)

The two parent functions

f(x)=xf(x) = \sqrt{x} g(x)=x3g(x) = \sqrt[3]{x}
key points (0, 0), (1, 1), (4, 2), (9, 3) (−8, −2), (−1, −1), (0, 0), (1, 1), (8, 2)
domain x≥0x \ge 0 (can’t take an even root of a negative) all real numbers
range y≥0y \ge 0 all real numbers
shape starts at the origin and rises, flattening S-shape through the origin, steepest at the center

Choose x-values that make the radicand a perfect square (0, 1, 4, 9) or a perfect cube (−8, −1, 0, 1, 8). Then every point is a whole number.

Transformations

y=ax−h+ky=ax−h3+ky = a\sqrt{x - h} + k \qquad\qquad y = a\sqrt[3]{x - h} + k

Change Effect
x−hx - h inside shift right h (left if it reads x+hx + h)
+k+ k outside shift up k
|a|>1\lvert a\rvert > 1 vertical stretch; 0<|a|<10 < \lvert a\rvert < 1: vertical shrink
a<0a < 0 reflection in the x-axis
−x\sqrt{-x} reflection in the y-axis

The starting point of the square-root graph (and the center of the cube-root graph) moves from (0, 0) to (h, k).

Worked Example 7: graph two transformed functions

(a) g(x)=2x−1−3g(x) = 2\sqrt{x - 1} - 3

  • Transformations: vertical stretch by 2, shift right 1, shift down 3. Starting point (1, −3).
  • Points: choose x−1=0,1,4,9x - 1 = 0, 1, 4, 9, i.e. x=1,2,5,10x = 1, 2, 5, 10. Then y=2(0)−3=−3y = 2(0) - 3 = -3, 2(1)−3=−12(1) - 3 = -1, 2(2)−3=12(2) - 3 = 1, 2(3)−3=32(3) - 3 = 3.
  • Domain x≥1x \ge 1; range y≥−3y \ge -3.

(b) h(x)=−x+23+4h(x) = -\sqrt[3]{x + 2} + 4

  • Transformations: reflection in the x-axis, shift left 2, shift up 4. Center (−2, 4).
  • Points: choose x+2=−8,−1,0,1,8x + 2 = -8, -1, 0, 1, 8, i.e. x=−10,−3,−2,−1,6x = -10, -3, -2, -1, 6. Then y=6,5,4,3,2y = 6, 5, 4, 3, 2.
  • Domain and range: all real numbers. The graph now falls from left to right (the reflection).

Worked Example 8: write a rule from a description

  • “Reflect f(x)=xf(x) = \sqrt{x} in the y-axis, then shift it up 3”: g(x)=−x+3g(x) = \sqrt{-x} + 3. Domain x≤0x \le 0 (because −x≥0-x \ge 0), range y≥3y \ge 3.
  • “Stretch f(x)=x3f(x) = \sqrt[3]{x} vertically by 3, then shift it right 4 and down 2”: g(x)=3x−43−2g(x) = 3\sqrt[3]{x - 4} - 2.

Most common mistakes on this quiz

  1. Root and power swapped: in am/na^{m/n} the denominator is the root. 82/38^{2/3} is 4, not 83\sqrt{8^3}.
  2. Making the answer negative because the exponent is negative: 9−1/2=139^{-1/2} = \tfrac{1}{3}, not −3-3.
  3. Missing ± when solving with an even root (x4=16x^4 = 16 has two real answers).
  4. Calling an odd root of a negative “not real”: −83=−2\sqrt[3]{-8} = -2 is real. Only even roots of negatives are not real.
  5. Forgetting to raise the number: (8x6)2/3=4x4(8x^6)^{2/3} = 4x^4, not 8x48x^4.
  6. Adding fractions without a common denominator: x1/2⋅x1/3=x5/6x^{1/2}\cdot x^{1/3} = x^{5/6}, not x2/5x^{2/5}.
  7. Shifting the wrong way: x−1\sqrt{x - 1} moves right 1.
  8. Domain of a cube-root function: it is all real numbers, not x≥hx \ge h.
