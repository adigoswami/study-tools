Physics All-Topics Review — Vectors, Kinematics and Forces

Conventions: g=9.81m/s2g = 9.81\ \text{m/s}^2 · up and right are positive · uu = initial velocity, vv = final velocity, aa = acceleration, tt = time, ss = displacement · angles measured from the +x+x axis unless stated.

1. Vectors

1.1 Scalar or vector

Scalar Vector
Has size (magnitude) only size and direction
Examples distance, speed, time, mass, energy, temperature displacement, velocity, acceleration, force, weight
Adds by ordinary arithmetic tip-to-tail or components

A vector is drawn as an arrow: length = magnitude (to scale), arrowhead = direction. A negative vector has the same length and points the opposite way.

1.2 Adding vectors

  • Same line: add with signs. +8N+8\ \text{N} and −3N-3\ \text{N} give +5N+5\ \text{N}.
  • Tip-to-tail (drawing): put the tail of the second vector at the tip of the first. The resultant runs from the first tail to the last tip.
  • Perpendicular vectors (Pythagoras):

R=A2+B2tanθ=BAR = \sqrt{A^2 + B^2} \qquad \tan\theta = \frac{B}{A}

Why: tip-to-tail, two perpendicular vectors form the legs of a right triangle and the resultant is the hypotenuse.

1.3 Components

Any vector AA at angle θ\theta from the xx-axis is the sum of a horizontal and a vertical part:

Ax=AcosθAy=AsinθA_x = A\cos\theta \qquad A_y = A\sin\theta

Why: in the right triangle with hypotenuse AA, cosθ=AxA\cos\theta = \frac{A_x}{A} and sinθ=AyA\sin\theta = \frac{A_y}{A}.

Back from components to the vector:

A=Ax2+Ay2θ=tan−1(AyAx)A = \sqrt{A_x^2 + A_y^2} \qquad \theta = \tan^{-1}\!\left(\frac{A_y}{A_x}\right)

Signs by quadrant: left means Ax<0A_x < 0, down means Ay<0A_y < 0. Always check the angle against a sketch (the calculator’s tan−1\tan^{-1} only returns angles between −90°-90° and 90°90°).

1.4 The component method (any two or more vectors)

  1. Resolve every vector into xx and yy components.
  2. Add: Rx=Ax+BxR_x = A_x + B_x, Ry=Ay+ByR_y = A_y + B_y.
  3. Rebuild: R=Rx2+Ry2R = \sqrt{R_x^2 + R_y^2}, θ=tan−1(Ry/Rx)\theta = \tan^{-1}(R_y / R_x).

Example. A=5.0mA = 5.0\ \text{m} at 30°30°, B=3.0mB = 3.0\ \text{m} at 120°120°.

xx yy
AA 5.0cos30°=4.335.0\cos 30° = 4.33 5.0sin30°=2.505.0\sin 30° = 2.50
BB 3.0cos120°=−1.503.0\cos 120° = -1.50 3.0sin120°=2.603.0\sin 120° = 2.60
RR 2.832.83 5.105.10

R=2.832+5.102=5.83mR = \sqrt{2.83^2 + 5.10^2} = 5.83\ \text{m}, θ=tan−1(5.10/2.83)=61°\theta = \tan^{-1}(5.10 / 2.83) = 61° above the +x+x axis.

Subtracting: A−B=A+(−B)A - B = A + (-B). Reverse BB, then add.

Equilibrium: if the vectors add to zero, the object is in equilibrium (Rx=0R_x = 0 and Ry=0R_y = 0).

1.5 Scale drawings

Choose a scale (for example 1 cm : 10 N), draw each vector with ruler and protractor, measure the resultant, and convert back. Real size = drawing size × scale factor.

2. Motion in a straight line

Quantity Definition Type
Distance total path length scalar
Displacement ss change in position, start to finish vector
Average speed distancetime\dfrac{\text{distance}}{\text{time}} scalar
Average velocity vavg=ΔxΔtv_{avg} = \dfrac{\Delta x}{\Delta t} vector
Acceleration a=ΔvΔt=v−uta = \dfrac{\Delta v}{\Delta t} = \dfrac{v - u}{t} vector

Speeding up: aa and vv have the same sign. Slowing down: opposite signs. Negative acceleration does not always mean slowing down.

2.1 The kinematic equations (constant acceleration only)

S1. From the definition of acceleration, a=v−uta = \frac{v - u}{t}:

v=u+atv = u + at

S0. With constant aa, velocity changes evenly, so the average velocity is u+v2\frac{u + v}{2}:

s=12(u+v)ts = \tfrac{1}{2}(u + v)\,t

S2. Put v=u+atv = u + at into S0:

s=12(u+u+at)t=ut+12at2s = \tfrac{1}{2}(u + u + at)\,t = ut + \tfrac{1}{2}at^2

S3. From S1, t=v−uat = \frac{v - u}{a}. Put it into S0: s=(v+u)(v−u)2a=v2−u22as = \frac{(v + u)(v - u)}{2a} = \frac{v^2 - u^2}{2a}, so

v2=u2+2asv^2 = u^2 + 2as

Choosing: list the five quantities s,u,v,a,ts, u, v, a, t. You know three and want one; use the equation that does not contain the fifth.

Example. A car goes from rest to 25 m/s in 10 s. a=25−010=2.5m/s2a = \frac{25 - 0}{10} = 2.5\ \text{m/s}^2; s=12(0+25)(10)=125ms = \frac{1}{2}(0 + 25)(10) = 125\ \text{m}.

2.2 Free fall

Only gravity acts: a=−g=−9.81m/s2a = -g = -9.81\ \text{m/s}^2 (up positive), the same for every mass.

  • At the top of the flight v=0v = 0, but aa is still −9.81m/s2-9.81\ \text{m/s}^2.
  • Time up = time down, and the speed is the same at the same height.

Example. Dropped from 45 m: s=12gt2⇒t=2(45)9.81=3.03ss = \frac{1}{2}gt^2 \Rightarrow t = \sqrt{\frac{2(45)}{9.81}} = 3.03\ \text{s}; v=gt=29.7m/sv = gt = 29.7\ \text{m/s}.

2.3 Motion graphs

Graph Slope gives Area under the line gives

Position–time: straight line = constant velocity, curve = accelerating, flat = at rest. Velocity–time: flat = constant velocity, straight sloped line = constant acceleration, crossing the axis = changing direction.

3. Projectile motion

Key idea: horizontal and vertical motions are independent. Horizontal: constant velocity (ax=0a_x = 0). Vertical: free fall (ay=−ga_y = -g). They share the same time tt.

Launch speed uu at angle θ\theta: ux=ucosθu_x = u\cos\theta, uy=usinθu_y = u\sin\theta.

x=uxtvy=uy−gty=uyt−12gt2x = u_x t \qquad v_y = u_y - gt \qquad y = u_y t - \tfrac{1}{2}gt^2

3.1 Launched from the ground, landing at the same height

  • Time of flight. Set y=0y = 0: t(uy−12gt)=0t\,(u_y - \frac{1}{2}gt) = 0, so T=2usinθgT = \dfrac{2u\sin\theta}{g}.
  • Maximum height. At the top vy=0v_y = 0; from vy2=uy2−2gHv_y^2 = u_y^2 - 2gH: H=u2sin2θ2gH = \dfrac{u^2\sin^2\theta}{2g}.
  • Range. R=uxT=2u2sinθcosθg=u2sin2θgR = u_x T = \dfrac{2u^2\sin\theta\cos\theta}{g} = \dfrac{u^2\sin 2\theta}{g}. Largest at 45°45°; angles that add to 90°90° give the same range.

Example. u=20m/su = 20\ \text{m/s} at 30°30°: ux=17.3u_x = 17.3, uy=10.0m/su_y = 10.0\ \text{m/s}. T=2(10.0)9.81=2.04sT = \frac{2(10.0)}{9.81} = 2.04\ \text{s}; H=10.022(9.81)=5.10mH = \frac{10.0^2}{2(9.81)} = 5.10\ \text{m}; R=17.3×2.04=35.3mR = 17.3 \times 2.04 = 35.3\ \text{m}.

3.2 Launched horizontally from a height hh

uy=0u_y = 0, so the fall time depends only on the height:

t=2hgx=uxtvy=gtspeed=ux2+vy2t = \sqrt{\frac{2h}{g}} \qquad x = u_x t \qquad v_y = gt \qquad \text{speed} = \sqrt{u_x^2 + v_y^2}

Example. 15 m/s off a 20 m cliff: t=2(20)9.81=2.02st = \sqrt{\frac{2(20)}{9.81}} = 2.02\ \text{s}; x=15×2.02=30.3mx = 15 \times 2.02 = 30.3\ \text{m}; vy=19.8m/sv_y = 19.8\ \text{m/s}; impact speed =152+19.82=24.8m/s= \sqrt{15^2 + 19.8^2} = 24.8\ \text{m/s}.

3.3 Launched at an angle from a height

Take the launch point as the origin. Landing at depth hh below it means y=−hy = -h:

−h=uyt−12gt2-h = u_y t - \tfrac{1}{2}gt^2

Solve this quadratic for tt (keep the positive root), then x=uxtx = u_x t.

4. Relative velocity

v→AC=v→AB+v→BC\vec{v}_{AC} = \vec{v}_{AB} + \vec{v}_{BC}

Read it as “velocity of A relative to C = A relative to B + B relative to C”. The inner letters match. Also v→AB=−v→BA\vec{v}_{AB} = -\vec{v}_{BA}.

  • Same line: two cars at 30 m/s and 20 m/s. Same direction: relative speed 10 m/s. Opposite directions: 50 m/s.
  • Boat crossing a river: boat 4.0 m/s straight across, current 3.0 m/s. Speed relative to the bank =4.02+3.02=5.0m/s= \sqrt{4.0^2 + 3.0^2} = 5.0\ \text{m/s}, at tan−1(3.0/4.0)=36.9°\tan^{-1}(3.0/4.0) = 36.9° downstream of straight across. River 100 m wide: crossing time =1004.0=25s= \frac{100}{4.0} = 25\ \text{s} (uses only the across component); drift downstream =3.0×25=75m= 3.0 \times 25 = 75\ \text{m}.

5. Uniform circular motion

Constant speed, but the direction keeps changing, so the object is accelerating, toward the center.

v=2πrTac=v2rFc=mv2rv = \frac{2\pi r}{T} \qquad a_c = \frac{v^2}{r} \qquad F_c = \frac{mv^2}{r}

  • TT = period (time for one lap); frequency f=1Tf = \frac{1}{T}.
  • Velocity is tangent to the circle. Acceleration and net force point to the center (centripetal).
  • Centripetal force is not a new force. It is the net force supplied by tension, friction, gravity or the normal force. If it vanishes, the object moves off in a straight line along the tangent.

Example. r=0.50mr = 0.50\ \text{m}, T=2.0sT = 2.0\ \text{s}, m=0.20kgm = 0.20\ \text{kg}: v=2π(0.50)2.0=1.57m/sv = \frac{2\pi(0.50)}{2.0} = 1.57\ \text{m/s}; ac=1.5720.50=4.93m/s2a_c = \frac{1.57^2}{0.50} = 4.93\ \text{m/s}^2; Fc=0.20×4.93=0.99NF_c = 0.20 \times 4.93 = 0.99\ \text{N}.

6. Newton’s laws of motion

First law (inertia). An object at rest stays at rest, and an object in motion keeps moving at constant velocity, unless a net external force acts on it.

∑F→=0⇔v→=constant(a→=0)\sum \vec{F} = 0 \iff \vec{v} = \text{constant} \quad (\vec{a} = 0)

Inertia is the resistance to a change in motion; mass measures it. Constant velocity means balanced forces, not “no forces”.

Second law. The acceleration of an object is directly proportional to the net force on it, inversely proportional to its mass, and in the direction of the net force.

F→net=ma→1N=1kg·m/s2\vec{F}_{net} = m\vec{a} \qquad 1\ \text{N} = 1\ \text{kg·m/s}^2

Apply it separately in each direction: ∑Fx=max\sum F_x = ma_x, ∑Fy=may\sum F_y = ma_y.

Third law. When object A exerts a force on object B, B exerts a force on A that is equal in size and opposite in direction.

F→A on B=−F→B on A\vec{F}_{A \text{ on } B} = -\vec{F}_{B \text{ on } A}

The two forces act on different objects, so they never cancel each other. They are the same type of force and exist together. (A book’s weight and the normal force from the table are not a third-law pair: both act on the book.)

Mass and weight. Mass (kg) is the amount of matter and is the same everywhere. Weight is the force of gravity: W=mgW = mg (N).

Apparent weight (elevator). The scale reads the normal force. From N−mg=maN - mg = ma:

N=m(g+a)N = m(g + a)

Accelerating up: heavier. Accelerating down: lighter. Constant velocity: N=mgN = mg. Free fall (a=−ga = -g): N=0N = 0.

Terminal velocity. Air drag grows with speed. When drag equals weight, the net force is zero and the speed stays constant.

Example. A 60 kg person in an elevator accelerating upward at 2.0m/s22.0\ \text{m/s}^2: N=60(9.81+2.0)=709NN = 60(9.81 + 2.0) = 709\ \text{N}.

7. Free-body diagrams, friction, inclines, connected objects

7.1 Free-body diagram (FBD)

Draw the object as a dot. Draw only the forces acting on it, each as an arrow from the dot, labeled: weight mgmg (down), normal NN (perpendicular to the surface), tension TT (along the rope, away from the object), friction ff (along the surface, opposing sliding), applied force. Never draw “mama” or velocity as a force.

Then: choose axes → resolve tilted forces into components → write ∑F=ma\sum F = ma for each axis → solve.

7.2 Friction

fs≤μsNfk=μkNf_s \le \mu_s N \qquad f_k = \mu_k N

  • Static friction matches the push exactly, up to a maximum μsN\mu_s N. Kinetic friction is constant once sliding; usually μk<μs\mu_k < \mu_s.
  • On a level surface with only horizontal pushes, N=mgN = mg. If a force has a vertical part, NN changes.

Example. A 10 kg box is pulled horizontally with 50 N; μk=0.30\mu_k = 0.30. N=10(9.81)=98.1NN = 10(9.81) = 98.1\ \text{N}; fk=0.30(98.1)=29.4Nf_k = 0.30(98.1) = 29.4\ \text{N}; a=50−29.410=2.06m/s2a = \frac{50 - 29.4}{10} = 2.06\ \text{m/s}^2.

7.3 Inclined plane (angle θ\theta)

Tilt the axes along and perpendicular to the slope. Weight resolves into mgsinθmg\sin\theta down the slope and mgcosθmg\cos\theta into the slope.

Perpendicular: N=mgcosθN = mg\cos\theta. Along the slope (sliding down): mgsinθ−μkmgcosθ=mamg\sin\theta - \mu_k mg\cos\theta = ma, so

a=g(sinθ−μkcosθ)frictionless: a=gsinθa = g(\sin\theta - \mu_k\cos\theta) \qquad \text{frictionless: } a = g\sin\theta

A block just stays at rest when mgsinθ=μsmgcosθmg\sin\theta = \mu_s mg\cos\theta, that is tanθ=μs\tan\theta = \mu_s.

Example. θ=30°\theta = 30°, μk=0.20\mu_k = 0.20: a=9.81(0.500−0.20×0.866)=3.21m/s2a = 9.81(0.500 - 0.20 \times 0.866) = 3.21\ \text{m/s}^2.

7.4 Connected objects

Same rope: same tension and the same size of acceleration. Write Fnet=maF_{net} = ma for each object, then add the equations so TT cancels.

Atwood machine (m2>m1m_2 > m_1): m2g−T=m2am_2 g - T = m_2 a and T−m1g=m1aT - m_1 g = m_1 a. Adding:

a=(m2−m1)gm1+m2T=2m1m2gm1+m2a = \frac{(m_2 - m_1)g}{m_1 + m_2} \qquad T = \frac{2m_1 m_2 g}{m_1 + m_2}

Block on a table (m1m_1) pulled by a hanging mass (m2m_2): m2g−T=m2am_2 g - T = m_2 a and T−μkm1g=m1aT - \mu_k m_1 g = m_1 a, so

a=(m2−μkm1)gm1+m2a = \frac{(m_2 - \mu_k m_1)g}{m_1 + m_2}

Example. Atwood, m1=2.0kgm_1 = 2.0\ \text{kg}, m2=3.0kgm_2 = 3.0\ \text{kg}: a=(1.0)(9.81)5.0=1.96m/s2a = \frac{(1.0)(9.81)}{5.0} = 1.96\ \text{m/s}^2; T=2(2.0)(3.0)(9.81)5.0=23.5NT = \frac{2(2.0)(3.0)(9.81)}{5.0} = 23.5\ \text{N}.

8. Mixed check (answers below)

  1. Find the components of a 50 N force at 37°37° above the +x+x axis.
  2. A hiker walks 6.0 km east, then 8.0 km north. Find the distance walked and the displacement.
  3. A ball is thrown straight up at 14.7 m/s. Find the time to the top and the maximum height.
  4. A marble rolls off a 1.25 m high table at 4.0 m/s. How far from the table does it land?
  5. A plane flies 200 m/s north in a 50 m/s wind blowing east. Find its velocity relative to the ground.
  6. A 1000 kg car takes a 50 m radius curve at 20 m/s. Find the centripetal acceleration and the force. What supplies it?
  7. A 5.0 kg block is pushed with 20 N on a level floor. Find aa with no friction, then with μk=0.20\mu_k = 0.20.
  8. A 2.0 kg block slides down a frictionless 25°25° incline. Find its acceleration.
  9. On a velocity–time graph, what do the slope and the area represent?
  10. A book rests on a table. Name the third-law partner of the book’s weight.
